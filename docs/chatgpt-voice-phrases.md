# Озвучка ChatGPT по предложениям

В режиме `hybrid` с `llm_api: chatgpt` мост может начать озвучивать ответ по подписке, пока модель ещё пишет. Чтобы включить эту возможность, задайте `QUASAR_CHATGPT_VOICE_PROBE=phrases` в окружении процесса Bridge и перезапустите его. Для standalone-установки переменную можно задать в `runtime.env`. Без этого значения действует обычная маршрутизация.

Начинайте **каждую** нужную реплику словами «тест потока»: «Алиса, тест потока, расскажи сказку», затем «Тест потока, придумай другой конец». Префикс выбирает ChatGPT без инструментов и не попадает в вопрос модели. Такой запрос виден в журнале как `native_route_decision` с `source=chatgpt_voice_probe`. Озвучивает ответ штатный синтезатор Алисы.

Первое готовое предложение отправляется на синтез сразу, следующие — по очереди в тот же аудиопоток. Если очередь заполнилась или ответ модели уже завершён, оставшийся текст озвучивается одним фрагментом. Если первая подходящая фраза так и не появилась, колонка получает обычный полный ответ.

[Результат проверки на Станции Лайт 1](validation.md#потоковая-озвучка-chatgpt-по-подписке-на-станции-лайт-1--24-ноября-2026). Офлайн-проверка без колонки: `go test -race ./internal/bridge -run TestChatGPTProbeAudioBeforeCompletion`.
