# Потоковая озвучка ChatGPT по подписке

В `mode: hybrid` с `llm_api: chatgpt` мост автоматически озвучивает голосовые ответы ChatGPT по мере генерации. Дополнительных настроек, переменных окружения или специальных слов не требуется. Решение, отвечает Яндекс или ChatGPT, принимают обычные правила маршрутизации и контекст диалога. Это относится и к переходу на LLM после отказа Яндекса.

Первую готовую фразу мост отправляет на синтез сразу, следующие — по очереди в тот же аудиопоток. Длинный текст без пунктуации разделяется на границе слов. История диалога сохраняет подтверждённый ответ целиком. Если провайдер не прислал пригодных для речи фрагментов, мост озвучит подтверждённый текст после завершения запроса.

Настроенные инструменты и веб-поиск остаются доступны. Колонка не читает классификацию маршрута, служебные сообщения, аргументы вызовов или комментарии о ходе работы. Когда инструменты доступны, для досрочной озвучки подписочный API должен пометить сообщение как `final_answer`; если метки нет, мост дождётся подтверждённого ответа. Команды, которым положено запустить медиа без речи, сохраняют это поведение.
